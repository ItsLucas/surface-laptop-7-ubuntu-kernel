Surface Laptop 7 Ubuntu 内核软件源

适用于 Ubuntu 26.10 / arm64 / Surface Laptop 7 13.8 英寸（Romulus13），使用已有 GRUB2 启动环境。

candidate 提供通过构建、签名和打包测试的候选版本；实机验证后才进入 stable。当前订阅文件选择 candidate。

添加软件源

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://mirrors.5cena.cc/sl7/sl7-archive-keyring.asc | sudo tee /etc/apt/keyrings/sl7-archive-keyring.asc >/dev/null
curl -fsSL https://mirrors.5cena.cc/sl7/sl7.sources | sudo tee /etc/apt/sources.list.d/sl7.sources >/dev/null
sudo apt update
sudo apt install linux-sl7

软件源签名密钥指纹：EFC6 6FC4 3239 A82F 1909 B2A6 283F 8715 8DF0 52D9。

安装与更新

安装时自动生成对应 initrd 并更新 GRUB。保持 linux-sl7 元包已安装，后续 sudo apt upgrade 即可获取新内核。旧内核保留供回退，不自动重启。

Secure Boot 需要信任内核的启动证书；APT 密钥不能替代 MOK。已有这套密钥的 Surface 无需重复登记。固件、iptsd、校准和机器专用配置沿用本机现有内容；此源目前不提供内核 headers。
